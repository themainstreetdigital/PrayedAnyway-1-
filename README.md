# Prayed Anyway

A faceless YouTube channel exploring biblical concepts for Gen Z and 20-somethings.
Videos run 8–15 minutes in an aesthetic that is **dark, moody, hopeful, and whimsical** —
candlelight and film grain, honest doubt and stubborn hope.

> *"The light shines in the darkness, and the darkness has not overcome it."* — John 1:5

## What's in this repo

| Path | What it is |
|---|---|
| `docs/01-brand-identity.md` | Channel identity, visual language, color, type, music direction |
| `docs/02-audience.md` | Who we're making this for and what actually reaches them |
| `docs/03-video-formats.md` | Five repeatable faceless formats, beat-timed for 8–15 min |
| `docs/04-production-workflow.md` | The full pipeline: write → voice → visuals → edit → publish, with tools |
| `docs/05-script-template.md` | Copy-paste beat sheet for every new script |
| `scripts/` | Finished and in-progress video scripts (one full example included) |
| `content/video-ideas.md` | 30 video ideas mapped to formats, organized by series |

## The thesis

Most Christian content on YouTube talks **at** Gen Z — polished, certain, bright.
This channel sits **with** them: in the dark, in the doubt, in the 2am questions —
and finds the hope that was already hiding in the text. The Bible is full of people
who prayed angry, prayed doubting, prayed exhausted... and prayed anyway.
That's the channel.

## How to start a new video

1. Pick an idea from `content/video-ideas.md` (or add a new one).
2. Copy `docs/05-script-template.md` into `scripts/` as `NN-working-title.md`.
3. Write to the beat sheet. Check the script against the voice rules in `docs/01-brand-identity.md`.
4. Follow `docs/04-production-workflow.md` to produce it.
